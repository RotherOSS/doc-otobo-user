Search
======

Search functions can be used to search everything inside OTOBO.
There are two search functions available: the standard search and the Elasticsearch function.

The standard search function is used to search for linkable objects like tickets, FAQs and Configuration Items in the CMDB.
It directly searches the database for items of one type only and returns the results in a list.

However, you may also search for all objects in OTOBO using the Elasticsearch index.
Results are obtained nearly instantly, even for large amounts of data.
